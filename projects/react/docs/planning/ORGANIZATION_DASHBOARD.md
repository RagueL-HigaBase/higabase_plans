# Organization Dashboard

Status: PLANNED

## Purpose
Organization-level dashboard for company-wide information and actions.

This is not a Company Profile page and must not absorb Location-specific fields.

## Current state
The route exists at:
- `/organization/dashboard`.

The current surface is intentionally minimal after removal of the obsolete Company Profile presentation page.

## Design rule
Dashboard content must be introduced only through separately approved blocks.

Location data belongs to the reusable Location architecture and must not be duplicated here.
